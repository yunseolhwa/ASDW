## Setup Script

Configured Windows setup script:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\validate_public_equity_project.ps1
```

This validates the SQLite schema, seed data, PM session views, and generated
database integrity checks.

## Cleanup Script

Configured Windows cleanup script:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\clean_public_equity_outputs.ps1
```

This removes generated public-equity outputs such as `artifacts/`, `logs/`, and
the dashboard build folder. It does not delete source files.

## Actions

Configured actions:

### Validate public equity project

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\validate_public_equity_project.ps1
```

Runs the schema and PM database validation suite.

### Build public equity database

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\build_public_equity_database.ps1
```

Builds the SQLite artifact and exports dashboard JSON.

### Run public equity dashboard

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\run_public_equity_dashboard.ps1
```

Starts the local Vite dashboard on `127.0.0.1:5173`.

### Clean generated outputs

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\clean_public_equity_outputs.ps1
```

Removes generated local outputs that can be recreated.
